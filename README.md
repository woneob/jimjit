# jimjit (짐짓)

> **짐짓** — 일부러 맞춤법을 틀려줍니다.

AI가 쓴 글은 너무 깔끔합니다. jimjit은 한국어 글에 **사람의 실수**를 입힙니다. 손이 미끄러진 오타, 몰라서 틀리는 맞춤법, 늘 그렇게 쓰는 습관 같은 것들이요. 문장과 내용은 그대로 두고 결만 흐트러뜨립니다.

```
$ jimjit "아 진짜 괜찮아? 싫어하면 어떡해. 오늘은 좀 더 생각해볼게." -l 8 -p mobile -s 32
아 진자 괜찮아? 싫어하면 어떻해. 오늘은 좀더 생각 해볼께
```

## 실수의 세 종류

| 종류 | 성질 | 예 |
|---|---|---|
| **손 실수** | 무작위로 난다 | 괜찮아 → 괜찬아, 진짜 → 진자, 있는데 → 있는대 |
| **몰라서 틀림** | 그 사람은 글 전체에서 **일관되게** 틀린다 | 됐 → 됬, 할게 → 할께, 금세 → 금새, 다르다 → 틀리다 |
| **습관** | 대부분의 자리에서 일관된다 | 할 수 있다 → 할수있다, 공부하다 → 공부 하다, 줄 끝 마침표 생략, 번역투(기본 꺼짐) |

jimjit은 글마다 먼저 "이 글을 쓴 사람"을 정합니다. 무엇을 모르고 어떤 습관이 있는지를 정한 뒤 실수를 넣습니다. 그래서 "됬"이라고 쓰는 사람은 끝까지 "됬"이라고 씁니다.

## 지키는 것

- 마크다운 코드(`` ``` ``·`~~~` 코드 블록, 들여쓰기 코드 블록, 인라인 코드), HTML 태그·주석, URL, 이메일, 파일 경로, 마크다운 링크, 숫자, 영문, `--keep` 으로 지정한 단어
- 문장의 첫 단어 (첫 단어 오타는 뜻을 흐리기 쉬움)
- 한 단어에는 실수 하나만, 붙어 있는 두 단어에 연달아 내지 않음
- 오타가 우연히 비속어를 만들면 그 오타는 버림
- 오해 소지가 큰 오류(결재 → 결제, 잊어버리다 → 잃어버리다)는 레벨 7부터

## 사용법

Node.js 18 이상이면 됩니다. 의존성은 없습니다.

### 명령줄 (CLI)

```bash
npm install -g jimjit
```

설치하지 않고 한 번만 써 보려면 `jimjit` 대신 `npx jimjit`으로 실행하세요.

```bash
jimjit "텍스트" --level 5
jimjit --file 글.txt --level 3 --profile work --keep "디지털 멀미" --report
jimjit --list   # 프로필, 실수 규칙, 오류 id 목록
```

바꿀 글은 인자, `--file`, 파이프 중 하나로 넣습니다. 옵션은 모두 선택입니다.

| 옵션                                | 설명                                                                                                     | 기본값                                                                     |
| --------------------------------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| `-l, --level <1-10>`              | 실수의 양. 1은 거의 티 안 나게, 10은 덕후 수준                                                                         | `3`                                                                     |
| `-p, --profile <이름>`              | `default`(일반: 특정 상황을 가정하지 않음), `work`(업무 메시지), `mobile`(모바일 채팅), `community`(커뮤니티), `bookish`(번역서 문체)  | `default`                                                               |
| `-s, --seed <값>`                  | 결과를 고정하는 번호. 같은 값을 주면 같은 결과가 다시 나옵니다. 이번에 쓰인 값은 `--report`에서 볼 수 있습니다                                  | 없음 (매번 달라짐)                                                             |
| `-k, --keep <단어,…>`               | 실수를 넣지 않을 단어                                                                                           | 없음                                                                      |
| `-f, --file <경로>`                 | UTF-8 파일에서 읽기                                                                                          | 없음                                                                      |
| `--only` / `--without` / `--with` | 실수 규칙 선택. `--only`는 이 규칙만, `--without`은 이 규칙을 끄고, `--with`는 기본 꺼진 규칙을 켭니다. 이름은 아래 [실수 규칙](#실수-규칙) 표 참고 | 번역투(`translationese`)만 꺼져 있고 나머지 실수 규칙은 모두 켜짐. `bookish` 프로필에서는 번역투도 켜짐 |
| `--mis <id,…>`                    | "잘못 알고 있는 표현"을 이 오류들로만 고정 (예: `--mis 됬,할께`). 쓸 수 있는 id는 `jimjit --list`로 확인                         | 없음 (확률로 고름)                                                             |
| `-r, --report`                    | 글쓴이 컨셉(잘못 알고 있는 표현, 성향)과 바꾼 내용을 stderr에 출력. 결과 글(stdout)에는 섞이지 않음                    | 꺼짐                                                                      |
| `--json`                          | 결과 전체를 JSON으로 출력                                                                                       | 꺼짐                                                                      |
| `--list`                          | 프로필, 실수 규칙, 오류 id 목록을 보여 주고 끝냄 (글을 넣지 않아도 됨)                                                           | -                                                                       |
| `-h, --help`                      | 도움말                                                                                                    |                                                                -        |

> **Windows:** PowerShell에서 한글을 파이프로 넘기면 인코딩이 깨질 수 있습니다. `--file` 을 쓰세요.

#### 리포트 (`--report`)

결과 글 아래에 jimjit이 정한 글쓴이와 바꾼 내용을 보여 줍니다. 리포트는 stderr로 나가므로 결과를 파일로 저장해도 섞이지 않습니다.

```text
$ jimjit "어제 말씀하신 자료는 오늘 안에 정리해서 보내 드릴게요. 혹시 빠진 내용이 있으면 편하게 말씀해 주세요." -s 1044 -r

result:
어제 말씀 하신 자료는 오늘 안에 정리헤서 보내 드릴께요. 혹시 빠진 내용이 잇으면 편하게 말씀해주세요.

• Seed: 1044
• Level: 3
• Profile: default

글쓴이 컨셉
┌─ 잘못 알고 있는 표현 8개 (* 이 글에 드러난 것) ──────────────────────┐
│                                                                      │
│  할게 → 할께*   아니에요 → 아니예요   봬요 → 뵈요   십시오 → 십시요  │
│  잠갔다 → 잠궜다   희한 → 희안   육개장 → 육계장   렌터카 → 렌트카   │
│                                                                      │
├─ 성향 ───────────────────────────────────────────────────────────────┤
│                                                                      │
│  띄어 써야 할 곳을 자주 붙여 쓰고, 가끔은 붙여 쓸 곳을 띄움          │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘

실수 5개
┌──────────────────────────────────────────────────────────────────────┐
│                                                                      │
│  [몰라서 틀림] 표기: 할께 (릴게 → 릴께)                              │
│  [습관] 띄어 쓸 곳을 붙임 (해 주 → 해주)                             │
│  [습관] 붙여 쓸 곳을 띄움 (말씀하신 → 말씀 하신)                     │
│  [손 실수] ㅐ/ㅔ 혼동 (정리해서 → 정리헤서)                          │
│  [손 실수] 쌍자음 놓침 (있으면 → 잇으면)                             │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

- **잘못 알고 있는 표현:** 이 글쓴이가 잘못 알고 있는 표기와 어휘입니다. 글에 그 표현이 있을 때만 실수로 드러나고, 드러난 것에는 `*`가 붙습니다.
- **성향:** 이 글쓴이의 띄어쓰기, 마침표, 번역투 습관입니다.
- 터미널에서는 테두리와 빈 상태 문구가 흐린 회색으로 보입니다. `NO_COLOR` 환경 변수를 두면 색을 쓰지 않습니다.

#### 실수 규칙

`--only`, `--without`, `--with`에 쓰는 이름입니다.

| 실수 규칙 | 실수의 종류 | 하는 일 |
|---|---|---|
| `slips` | 손 실수 | 오타 (괜찮아 → 괜찬아) |
| `knowledge` | 몰라서 틀림 | 맞춤법·어휘 혼동 (할게 → 할께) |
| `spacing` | 습관 | 띄어 쓸 곳을 붙여 씀 (할 수 있다 → 할수있다, 먹어 보다 → 먹어보다, 두 시간 → 두시간). 가끔은 붙여 쓸 곳을 띄움 (공부하다 → 공부 하다, 학교에서 → 학교 에서) |
| `period` | 습관 | 줄 끝 마침표 생략 |
| `translationese` | 습관 | 번역투 (회의를 했다 → 회의를 가졌다). 기본 꺼짐 |

예: `--without period`는 마침표는 그대로 두고, `--only slips`는 오타만 넣습니다.

### JavaScript API

```bash
npm install jimjit
```

```js
import { jimjit } from 'jimjit';
const src = '어제 말씀하신 자료는 오늘 안에 정리해서 보내 드릴게요. 혹시 빠진 내용이 있으면 편하게 말씀해 주세요. 일정이 바뀌면 바로 알려 드리겠습니다.';
const { text, changes, person, stats } = jimjit(src, { level: 6, seed: 9 });
```

입력과 출력을 나란히 보면 이렇습니다.

```text
입력  어제 말씀하신 자료는 오늘 안에 정리해서 보내 드릴게요. 혹시 빠진 내용이 있으면 편하게 말씀해 주세요. 일정이 바뀌면 바로 알려 드리겠습니다.
출력  어제 말씀 하신 자료는 오늘 안에 정리해서 보네 드릴께요. 혹시 빠진 내용이 있으면 편하게 말씀해주새요. 일정이 바뀌면 바로 알려드리겠습니다
```

반환값 전체는 이렇습니다 (`text`는 위 출력과 같아서 생략).

```json
{
  "changes": [
    { "category": "습관", "rule": "마침표 생략", "from": "다.", "to": "다" },
    { "category": "몰라서 틀림", "rule": "표기: 할께", "from": "릴게", "to": "릴께" },
    { "category": "습관", "rule": "띄어 쓸 곳을 붙임", "from": "해 주", "to": "해주" },
    { "category": "습관", "rule": "띄어 쓸 곳을 붙임", "from": "려 드리", "to": "려드리" },
    { "category": "습관", "rule": "붙여 쓸 곳을 띄움", "from": "말씀하신", "to": "말씀 하신" },
    { "category": "손 실수", "rule": "ㅐ/ㅔ 혼동", "from": "보내", "to": "보네" },
    { "category": "손 실수", "rule": "ㅐ/ㅔ 혼동", "from": "세요", "to": "새요" }
  ],
  "person": {
    "misconceptions": [
      "됬", "할께", "뵈요", "일찌기", "일부로", "어쨋든", "몇일", "설겆이",
      "오랫만", "무릎쓰고", "패쇄", "컨텐츠", "리더쉽", "렌트카", "틀리다", "붙이다"
    ],
    "habits": { "spacing": true, "period": true, "translationese": false }
  },
  "stats": { "words": 20, "flaws": 7, "rate": 0.35 },
  "seed": 9,
  "level": 6,
  "profile": "default"
}
```

| 필드 | 내용 |
|---|---|
| `changes` | 바꾼 자리마다 실수의 종류(`category`), 세부 규칙(`rule`), 바뀌기 전(`from`)과 후(`to`) |
| `person.misconceptions` | 이 글을 쓴 사람이 잘못 알고 있는 것. 글에 그 표현이 있을 때만 드러납니다 (이 예에서는 `할께`) |
| `person.habits` | 글쓴이의 습관: 띄어쓰기(`spacing`), 마침표 생략(`period`), 번역투(`translationese`) |
| `stats` | 한글 단어 수(`words`), 실수 개수(`flaws`), 단어당 실수 비율(`rate`). 한 단어에 실수가 겹칠 수 있어 `rate`는 1을 넘기도 합니다 |

`seed`를 주지 않으면 매번 다른 결과가 나옵니다. 위 예제처럼 `seed`를 고정하면 항상 같은 결과가 나옵니다.

### 에이전트 스킬

```bash
npx skills add woneob/jimjit -g
```

`-g`를 빼면 지금 프로젝트에만 설치됩니다. 설치할 에이전트(Claude Code, Codex, Cursor, Gemini CLI 등)는 설치할 때 고르거나 `-a claude-code`, `-a codex`처럼 지정합니다. 업데이트와 삭제는 `npx skills update jimjit`, `npx skills remove jimjit`로 합니다.

"이 글 짐짓 흐트러뜨려 줘, 레벨 5로" 같은 요청에 [SKILL.md](SKILL.md) 지침대로 동작합니다. 말투 변환이 함께 필요하면 AI가 먼저 말투를 바꾸고, jimjit은 마지막에 실수만 입힙니다.
